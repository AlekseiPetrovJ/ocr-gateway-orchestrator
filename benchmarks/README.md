

# **Инструменты подготовки данных и нагрузочного тестирования OCR-пайплайна**

Набор автономных инструментов для подготовки данных, проведения нагрузочного тестирования и пакетной загрузки документов в OCR-шлюз.

## Зачем это нужно (Stress & Performance Testing)
Данный инструментарий позволяет проверить отказоустойчивость и пропускную способность всей системы:
* **Нагрузочный тест (Stress-test)**: Пакетная отправка 100+ страниц в секунды создает плотную очередь в **RabbitMQ**, проверяя стабильность **Java-ядра**.
* **Профилирование воркера**: Позволяет оценить реальную утилизацию ресурсов при непрерывном инференсе моделей **Docling** на длинной дистанции.
* **Observability**: Благодаря интеграции с **Langfuse**, на большом объеме данных можно построить распределение задержек (Latencies) для каждого этапа пайплайна.

---

## 1. Подготовка окружения

Создаем изолированное виртуальное окружение, чтобы не конфликтовать с основным проектом:

```bash
# Создаем папки для работы
mkdir -p input output
# Инициализируем venv
python -m venv venv
```

Активация venv

**Windows (PowerShell):**
```powershell
.\venv\Scripts\Activate.ps1
```
**Linux / macOS:**
```bash
source venv/bin/activate
```


## 2. Установка зависимостей

Внутри активированного venv:
```bash
pip install pypdf requests
```

## 3. Нарезка PDF по страницам

1. Поместите исходные файлы в папку `input/`.
2. Запустите скрипт нарезки:
```bash
python split_pdf.py
```
_Результат: Каждая страница станет отдельным PDF-файлом в папке `output/` с сохранением порядка (001, 002...)._

## 4. Загрузка в OCR-шлюз

Запустите скрипт автоматической отправки всех нарезанных страниц:
```bash
python upload_pages.py
```
_Скрипт замерит время отправки каждой страницы и выведет `taskId` и `fileHash` для контроля._

## 5. Мониторинг и результат

После загрузки вы можете отслеживать задачи по следующим адресам:

- **Статус задачи:** `GET http://localhost:8080/api/v1/tasks/{taskId}`
- **Скачать результат:** `GET http://localhost:8080/api/v1/tasks/{taskId}/download`
- **Трассировка:** Langfuse UI (ищите сквозной трейс по `taskId` или `fileHash`).

---

**Примечание:** Для работы скачивания убедитесь, что в вашем `/etc/hosts` прописана строка `127.0.0.1 minio`.
