**Контекст:** Python SDK v3 перешел на стандарт OpenTelemetry, который несовместим с текущей реализацией Distributed Tracing в Java-ядре (разные форматы контекста и методов).  
**Решение:** Выполнить даунгрейд Python SDK до версии **2.x**.  
**Обоснование:**

1. **Совместимость:** Обеспечивает прямую склейку трейсов Java и Python по произвольному `trace_id`.
2. **Стабильность:** Избавляет от ошибок `AttributeError` и `unexpected keyword argument`, специфичных для ранних сборок v3.
3. **Скорость внедрения:** Позволяет использовать классический метод `.trace(id=...)`, который поддерживается сервером Langfuse v3.
